# Pilot v0.4.0

## ✨ Nouvelles fonctionnalités

- **MCP piloté par l'Assistant** : Pilot peut désormais se connecter à des **serveurs MCP** externes (par exemple un serveur de lecture web) pour étendre les capacités de ses agents. L'Assistant peut **choisir le serveur** à utiliser et le transmettre à l'agent chargé de la tâche.
- **Réglages — onglet « Serveurs MCP »** : configurez vos serveurs MCP (ajout, modification, suppression), activez ou désactivez le client MCP, testez la connexion à un serveur avant de l'utiliser.

## 🐛 Corrections

- **Relance propre des agents depuis l'Assistant** : après une délégation de tâche, le processus de l'agent restait vivant et, lors d'une nouvelle relance, reprenait l'ancienne conversation au lieu de démarrer du neuf. Désormais chaque relance démarre sur une **nouvelle session vierge**, avec un contexte propre, comme attendu.

## ⚡ Améliorations

- **Confirmation utilisateur par défaut** : avant qu'un agent utilise un serveur MCP, l'Assistant demande votre confirmation (réglable dans les Paramètres). Une fois la confirmation désactivée, il choisit et lance automatiquement.

**Remarque** : seul le transport `stdio` est supporté pour les serveurs MCP (les transports http/sse ne sont pas encore pris en charge).
