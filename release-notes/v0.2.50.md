# Pilot v0.2.50

## ✨ Nouvelles fonctionnalités

- **Multi-onglets agents** : ouvrez **plusieurs agents indépendants sur le même projet** grâce au bouton « ＋ » de la barre d'onglets. Chaque agent a sa **propre conversation persistée** et son propre canal d'événements. Les onglets supplémentaires sont renommables (double-clic sur le nom). À activer dans **Paramètres ⚙️ → Agent Pi → Multi-onglets agents**.

- **Purge automatique des sessions** : les sessions pi plus anciennes qu'un délai de rétention configurable sont **supprimées automatiquement en arrière-plan** (au démarrage puis toutes les heures), pour éviter l'accumulation de fichiers. Réglable dans **Paramètres ⚙️ → Agent Pi → Rétention des sessions (jours)** (défaut 15, `0` = désactivé). L'index et les tags des sessions supprimées sont nettoyés.

## 🎨 Améliorations

- **Boutons de choix / validation colorés** : les boutons de choix, de confirmation (Oui/Non) et d'options affichés par l'agent dans le chat ont désormais un **fond coloré semi-transparent** (comme le bouton « valider »), avec le texte de la couleur pleine pour rester lisible en thème clair comme en thème sombre.

- **Génération AGENTS.md plus claire** : un **spinner circulaire centré** s'affiche pendant la génération, avec masquage de l'overlay RAG pour éviter un double spinner.

- **Indicateur RAG harmonisé** : l'indicateur de construction de l'index RAG passe du sablier au **spinner circulaire centré**, cohérent avec celui du démarrage de l'agent.
