# Pilot v0.2.29

## 🐛 Corrections de stabilité

### 🔄 Le chat ne se fige plus après un compactage automatique

Lors d'un **compactage automatique** (contexte devenu trop grand), l'agent
pouvait s'arrêter et rester figé après « ✅ Compaction terminée », sans répondre
ni exécuter la suite. Désormais, si l'agent ne reprend pas tout seul, **Pilot le
relance automatiquement** en réémettant le dernier message avec le contexte
compacté. La conversation continue sans intervention.

- Fonctionne en **chat standard** comme en **mode orchestration**.
- Ne s'applique pas au compactage manuel (`/compact`) : rien n'est relancé.

### ⚡ Le chat ne gèle plus si Ollama est éteint (Context Engine)

Si le modèle d'embedding d'Ollama (utilisé pour le contexte automatique) n'était
pas disponible ou était lent, le **tout premier message** pouvait rester bloqué
« Ne répond pas ». Désormais :

- l'attente est **bornée par des timeouts courts** ;
- le message part **sans contexte** dès que le délai est dépassé (au lieu de
  geler) ;
- le rafraîchissement de l'index est limité aux fichiers les plus récents.
