# Pilot v0.4.13

## 🐛 Corrections

- **L'assistant ne reste plus muet pendant qu'un agent travaille** : quand tu
  suivais un agent en pleine tâche, il pouvait arriver que l'assistant n'affiche
  plus rien et paraisse figé. Il répond de nouveau normalement, sans attendre que
  l'agent ait fini.
- **Plus de compte rendu perdu** : le récapitulatif de fin de tâche d'un agent
  est maintenant déposé dans une boîte durable. Même si Pilot redémarre entre
  temps, le compte rendu n'est plus perdu : il est remis dès que l'assistant
  redevient disponible.
- **Le bon fichier de modèle d'avatar reste dans sa case** : dans les Paramètres,
  à l'onglet Avatar, choisir la fiche du visage (.vrm) remplissait par erreur
  une autre case. Chaque fichier va désormais dans la bonne. Le bouton en double
  a aussi été retiré.
- **Un long travail qui avance n'est plus coupé** : l'arrêt automatique ne
  stoppe plus un agent au milieu d'une opération longue et active. Seuls les
  vrais blocages sont interrompus.
- **Plafond de tours affiché correctement** : la valeur par défaut du nombre de
  tours affichée dans les Paramètres correspond de nouveau à la valeur
  réellement appliquée.

## ⚡ Améliorations

- **Licence MIT** : le projet est désormais accompagné de sa licence, clairement
  indiquée dans le dépôt.
- **Documentation de l'arrêt automatique** : l'arrêt automatique et son
  fonctionnement sont maintenant expliqués dans l'aide intégrée et la
  documentation.
