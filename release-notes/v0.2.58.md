# Pilot v0.2.58

## ✨ Nouvelles fonctionnalités
- **Relais des questions d'agent via l'Assistant (🧭)** : quand un agent du projet a besoin d'une décision de votre part (choix d'une approche, confirmation, saisie de texte), l'Assistant sert désormais d'interface. Tant que vous êtes sur l'onglet Assistant, la question de l'agent y est affichée avec les options proposées, vous pouvez la compléter ou la modifier, puis la réponse est transmise au bon agent, qui poursuit son travail.

## 🐛 Corrections
- Aucune correction dans cette version.

## ⚡ Améliorations
- Chaque agent est identifié dans le relais : les réponses ne sont jamais mélangées entre plusieurs agents qui travaillent en parallèle.
