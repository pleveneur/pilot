# Pilot v0.4.15

## ✨ Nouvelles fonctionnalités

- **Prévenu sur Telegram** : Pilot peut désormais t'envoyer un message Telegram
  lorsque l'agent a terminé sa tâche, lorsqu'une alerte se déclenche ou lorsqu'un
  agent est arrêté automatiquement. L'activation, le jeton du bot et
  l'identifiant de discussion se règlent dans les Paramètres. Tant que rien n'est
  configuré, rien ne change et aucun message n'est envoyé. À ce stade, Pilot se
  contente d'envoyer : il ne lit aucun message entrant.

## 🐛 Corrections

- **Plus de marque d'occupation fantôme** : après l'arrêt d'un agent, une trace
  d'occupation pouvait subsister et empêcher les demandes suivantes de démarrer.
  Elle est maintenant correctement effacée.
- **Agent introuvable signalé clairement** : une demande visant un agent qui
  n'existe pas est désormais refusée avec un message explicite, au lieu de
  partir en silence vers un autre agent.
- **Le bon onglet s'ouvre à la délégation** : lorsqu'une demande est déléguée à
  un agent, c'est l'onglet de l'agent réellement visé qui s'ouvre.
- **Réglages qui ne bloquent plus** : dans les Paramètres, la lecture de la
  configuration ne gèle plus le programme, et elle ne peut plus réécrire des
  valeurs d'usine à la place de vos réglages.

## ⚡ Améliorations

- **Sélecteur de modèle par onglet d'agent** : chaque onglet d'agent garde son
  propre choix de modèle, sans perturber les autres.
- **Documentation** : la nouvelle passerelle Telegram est décrite dans l'aide
  intégrée et la documentation du projet.
