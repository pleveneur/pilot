# Pilot v0.2.26

## 🛡️ Fiabilité & qualité

Cette version met l'accent sur la **robustesse** du Mode Orchestration et de la
revue de code assistée.

- **Socle de tests automatiques** : le projet dispose désormais de tests
  unitaires (Rust + JS) sur les fonctions critiques — parsing du plan, revue de
  code, granularité adaptative, validation post-tâche. Chaque nouvelle version
  est vérifiée avant publication pour éviter les régressions.

- **Correction d'un bug de détection des fichiers modifiés** : la détection des
  fichiers cités par l'agent (pour vérifier qu'une tâche a bien été réalisée)
  était défaillante — elle pouvait capturer des mots parasites ou oublier des
  fichiers. L'extraction est désormais précise, y compris pour les fichiers dans
  des sous-dossiers.
