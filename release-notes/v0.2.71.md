# Pilot v0.2.71

## ✨ Nouvelles fonctionnalités
- Tableau de bord : purge des fichiers inutiles. Le tableau de bord détecte automatiquement les éléments purgeables (dépendances, caches, sorties de build…) selon le type de projet. Cochez ce que vous voulez supprimer, confirmez, et l'espace est libéré. Le dossier `.git` n'est jamais supprimé (seule une compaction `git gc` est proposée).

## 🐛 Corrections
- Assistant : la zone de saisie n'est plus bloquée pendant le travail des agents. Quand l'Assistant lance une tâche sur des agents, il finit son tour immédiatement et vous pouvez continuer à lui parler ; il vous fait le compte-rendu à la fin.

## ⚡ Améliorations
- Tableau de bord : la taille réelle du projet sur disque (tout compris, y compris les dossiers de dépendances et de build) est désormais affichée à côté du graphique de répartition.
