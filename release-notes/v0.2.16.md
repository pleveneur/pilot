# Pilot v0.2.16

## ✨ Nouveautés

- **🎭 Équipe d'agents multi-rôles** : un bouton 🎭 du panneau d'actions lance
  une équipe d'agents spécialisés (coordinateur, architecte, codeur, reviewer,
  testeur, documenteur) qui collaborent séquentiellement sur une tâche. Le
  coordinateur reçoit votre demande, délègue chaque sous-tâche à l'agent adapté,
  puis synthétise la réponse finale.
  - Chaque agent se configure depuis l'onglet 🎭 lui-même : nom, icône,
    description, rôle (consigne système) et modèle (π / ℓ), lecture seule,
    conservation du contexte, limites d'appels.
  - Les agents sont partagés entre tous vos projets (`~/.pilot/agents.json`) et
    réinitialisables en un clic.
  - Garde-fous intégrés : profondeur d'appel, budget total, timeout d'inactivité,
    détection de cycle, bouton **⏹ Arrêter**.

## 🐛 Corrections

- **Agents — interface muette** : les callbacks de l'interface ne réagissaient
  jamais aux événements du bus d'agents (incohérence de nommage) : la run
  démarrait en arrière-plan mais rien ne s'affichait. Corrigé.
- **Agents — texte doublonné** : la réponse d'un agent n'est plus affichée en
  double dans la conversation.
- **Agents — demande utilisateur masquée** : votre demande s'affiche
  désormais dans le chat pendant toute la durée de la run (elle était effacée
  au démarrage).

## 🔧 Simplifications

- **Bouton 🎭 toujours visible** : plus besoin d'activer le mode Agents dans
  les Paramètres — le bouton apparaît dès qu'un projet est ouvert.
- **Fin du doublon du modèle coordinateur** : le modèle du coordinateur se règle
  uniquement dans l'éditeur d'agents (plus de sélecteur redondant dans les
  Paramètres globaux).
