# Pilot v0.2.74

## ✨ Nouvelles fonctionnalités
- **Orchestration multi-agents fiabilisée** : un seul agent de chaque spécialité peut travailler à la fois sur un même projet. Si une même spécialité est déjà active, la nouvelle demande est placée en file d'attente et lancée automatiquement dès que la tâche en cours se termine.
- **Arrêt automatique des agents délégués bloqués** : un agent lancé par l'Assistant 🧭 qui reste actif sans progresser (défaut : 10 minutes) est maintenant **arrêté automatiquement**. Son créneau est libéré pour l'agent en file d'attente, et un **diagnostic automatique** est lancé pour proposer des améliorations (sans action automatique : vous validez). Réglable dans **Paramètres ⚙️ → Agent**.
- **Brief structuré pour les agents appelés** : les consignes envoyées par l'Assistant aux agents qu'il délègue sont mieux structurées, pour des lancements plus fiables et des résultats plus complets.

## ⚡ Améliorations
- L'heure de dernière activité des agents délégués est désormais visible dans la liste des sessions, pour mieux suivre les tâches en cours.
- Le diagnostic d'anomalies est plus complet : il couvre l'arrêt automatique des agents bloqués en plus de la simple détection (chat principal, reviewer et Assistant ne sont jamais arrêtés automatiquement).
