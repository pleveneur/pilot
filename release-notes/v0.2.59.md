# Pilot v0.2.59

## ✨ Nouvelles fonctionnalités
- **Notification quand l'assistant a terminé** : vous pouvez maintenant recevoir une
  notification native (bannière Windows/macOS/Linux) quand l'Assistant (🧭) signale
  un événement **important** : une **tâche déléguée à un agent du projet est
  terminée**, ou une **anomalie** de suivi (ex. connexion au super-agent perdue).
  Réglable dans **Paramètres ⚙️ → Assistant → « Notifier quand l'Assistant a
  terminé une tâche déléguée ou signale une anomalie »**. Désactivé par défaut
  pour éviter la sur-notification : les réponses banales de l'Assistant ne
  déclenchent aucune notification.
- **Bouton sélectionné plus visible** : le choix (unique ou multiple) sélectionné
  dans les boutons posés par l'agent ou l'Assistant est désormais mis en évidence
  clairement, pour éviter toute ambiguïté sur votre réponse.
