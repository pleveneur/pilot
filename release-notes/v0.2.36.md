# Pilot v0.2.36

## ✨ Nouvelles fonctionnalités
- **Agents en parallèle** (onglet 🎭 Agents) : lancez plusieurs agents **simultanément** sur une même tâche via le bouton ⚡, ou laissez le coordinateur déléguer des sous-tâches indépendantes en parallèle. Chaque agent travaille dans sa propre bulle de réflexion et les résultats sont agrégés à la fin.
- **Mise à jour de l'agent Pi** : à l'ouverture de l'onglet agent, Pilot vérifie automatiquement si une nouvelle version de Pi est disponible et propose de la mettre à jour en un clic (option « Ne plus demander » disponible).
- **Liens cliquables dans la prévisualisation Markdown** : un lien interne ouvre le fichier cible dans un onglet, un lien externe (http/https) s'ouvre dans le navigateur, une ancre (`#section`) fait défiler la prévisualisation.
- **Scroll synchronisé en mode split** : la position de défilement est préservée pendant l'édition (plus de saut en haut à chaque frappe).
- **Navigation d'onglets améliorée** : `Ctrl+Tab` fonctionne aussi dans le terminal intégré, et `Ctrl+1`…`Ctrl+9` permet d'aller directement à un onglet par position.
- **Développer Pilot avec Pilot** : `npm run tauri dev` lance une version dev **séparée** de la version installée (config, sessions et port web indépendants) — les deux peuvent tourner en parallèle.

## 🐛 Corrections
- **Faux conflit après sauvegarde** : un fichier sauvegardé (auto-save ou `Ctrl+S`) n'est plus signalé à tort comme modifié de l'extérieur.
- **Indicateur d'activité** : la pastille d'un agent qui travaille en arrière-plan ne s'éteint plus à tort lors d'un simple changement de projet.
- **Menu natif sur les ascenseurs** : le menu système WebView2 qui apparaissait au clic droit sur une barre de défilement est supprimé ; un menu Copier/Couper/Coller le remplace dans l'éditeur et les champs de saisie.
