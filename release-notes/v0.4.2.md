# Pilot v0.4.2

## 🐛 Corrections

- Correction d'un bug où un agent standard figé (processus pi bloqué sans progression) pouvait bloquer Pilot indéfiniment : il est désormais arrêté automatiquement après le seuil configuré, comme les agents délégués. Les demandes en attente de l'Assistant sont transmises à un agent redémarré, et l'interface reflète correctement l'arrêt.
