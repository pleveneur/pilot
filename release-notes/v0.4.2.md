# Pilot v0.4.2

## ✨ Nouvelles fonctionnalités

- **Kanban Assistant** : le tableau de suivi multi-projets de l'Assistant (vue par client, quatre colonnes) s'ouvre désormais dans un onglet dédié, accessible depuis la barre latérale de l'onglet Assistant. L'Assistant peut piloter le tableau entièrement (création, modification, déplacement et suppression des tâches).
- **GDS — gestion des clés SSH serveur** : génération et gestion des clés SSH directement depuis la configuration (Phase A3).
- **GDS — configuration simplifiée** : secrets stockés hors du projet, mot de passe masqué, reconnexion automatique et synchronisation corrigée.
- **GDS — repos centralisés** : les référentiels GDS sont désormais déplacés hors du profil utilisateur pour corriger le clonage SSH.

## 🐛 Corrections

- Correction d'un bug où un agent standard figé (processus pi bloqué sans progression) pouvait bloquer Pilot indéfiniment : il est désormais arrêté automatiquement après le seuil configuré, comme les agents délégués. Les demandes en attente de l'Assistant sont transmises à un agent redémarré, et l'interface reflète correctement l'arrêt.
- **Connexion au superviseur perdue** : en cas de perte de connexion avec l'Assistant, la cause réelle (message de l'erreur) est désormais affichée au lieu d'un message générique, pour vous aider à diagnostiquer le problème.
- **Mode immersif** : la conversation s'ouvrait en haut (au premier message) au lieu du bas (dernier message) après une remontée de l'historique. Le suivi est corrigé.
- **Changement de modèle** : un changement de modèle sur un processus IA arrêté affiche désormais un message clair au lieu d'une erreur brute, et ne supprime plus votre texte en cours de saisie.
- **Verrou de run fantôme** : correction d'un verrou qui restait bloqué après un arrêt, empêchant le lancement d'un nouveau travail.
