# Pilot v0.4.7

## ✨ Nouvelles fonctionnalités

- **« Ajouter depuis GDS »** : un nouveau menu permet d'ajouter un projet à partir du gestionnaire de sources, en quelques clics.
- **Autoconfiguration Git à l'ajout d'un projet** : l'identité Git (nom et e-mail) est configurée automatiquement quand un projet est ajouté via le gestionnaire de sources.

## 🐛 Corrections

- **Verrous/cadenas sur les projets liés au GDS** : les cadenas sont désormais visibles en permanence et stylés de façon uniforme, quelle que soit la situation du projet.

## ⚡ Améliorations

- **Gestionnaire de sources refondu** : un projet lié utilise désormais un seul dossier local par projet, ce qui simplifie le suivi et évite les doublons.
