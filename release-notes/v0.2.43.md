# Pilot v0.2.43

## ✨ Nouvelles fonctionnalités
- **Modales animées** : les fenêtres (Paramètres, raccourcis, commandes projet, discussion inter-projets, etc.) s'ouvrent désormais avec une **animation de zoom fluide** depuis l'endroit où vous avez cliqué, jusqu'à leur taille finale.
- **Nouveaux onglets animés** : l'ouverture d'un fichier depuis l'explorateur ou d'un panneau (terminal, aperçu…) s'accompagne d'un **zoom depuis le point cliqué** sur le contenu. La bascule vers un onglet déjà ouvert reste instantanée.
- **Nouveau paramètre** (⚙️ → Général → Apparence) : **« Animer l'ouverture des modales »** — activé par défaut, y compris après mise à jour. Il force les animations même si la réduction de mouvement est active sur votre système ; le désactiver rétablit le respect strict de l'accessibilité.

## 🐛 Corrections
- **Thème de l'éditeur** : le changement de thème/sous-thème (clair/sombre) déclenchait une erreur et l'éditeur ne suivait plus correctement. Le basculement fonctionne désormais comme prévu.

## ⚡ Améliorations
- Les animations d'ouverture sont fluides (accélération GPU) et respectent la préférence de réduction de mouvement quand le paramètre est désactivé.
