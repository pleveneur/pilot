# Pilot v0.2.65
## ✨ Nouvelles fonctionnalités
- Assistant (🧭) : supervision multi-projets — suivi de l'activité des agents sur tous les projets, indicateurs d'activité fiables (point clignotant, statut correct pendant le travail).
- Assistant : délégation en arrière-plan (agent invisible) — lance un agent sans ouvrir son onglet, récupère le résultat à la fin.
- Assistant : arrêt de tous les agents ouverts (y compris les agents secondaires), avec fermeture de l'onglet de l'agent standard.
- Assistant : outil de planification (relances différées et périodiques) sur les tâches.
- Assistant : option d'héritage du contexte projet pour les agents spécifiques (RAG, mémoire projet, graphe de code) — activable dans la config.
- Assistant : paramètre activable pour appliquer le protocole quality-gate aux agents appelés.
- Assistant : mode « Assistant Only » immersif (plein écran, logo, toggles voix, mémorisation des préférences).
- Assistant : détection de boucle dans la réflexion du modèle (coupe automatiquement les boucles).
- Assistant : résumé de session non tronqué.
- Tableau de bord : carte de supervision des agents (état, activité).
- Assistant : snapshots de projet et accès à l'état Git (status/log) en lecture seule.
