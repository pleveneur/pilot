# Pilot v0.2.19

## 🐛 Corrections

- **Raccourcis alias de modèles restaurés (issue #6)** : la saisie de `/`
  dans le chat de l'agent affiche de nouveau la liste des alias définis
  dans l'onglet « Fournisseurs ». Les alias étaient perdus à l'initialisation
  (race condition) ainsi qu'après une reconnexion ou un redémarrage de
  l'agent — les deux cas sont désormais couverts.
- **Bouton « Réinitialiser les agents » corrigé (issue #4)** : il remet
  bien en place les 6 agents par défaut (coordinateur, architecte, codeur,
  reviewer, testeur, documenteur) au lieu d'effacer toute la liste.
- **Ouverture en double d'AGENTS.md** : le bouton de génération ferme
  désormais l'onglet existant avant de le rouvrir, plus de doublon.

## ✨ Nouveautés

- **Bouton 📄 AGENTS.md (issue #5)** : génère ou met à jour le fichier
  `AGENTS.md` (instructions projet pour l'agent) via le modèle actif du
  chat. L'agent analyse le projet (README, manifests, structure) et
  rédige un `AGENTS.md` concis et factuel. Pilot ne ré-injecte plus
  `AGENTS.md` dans le contexte : pi et plh le gèrent nativement.

## 🔧 Divers

- **Onglet « Fournisseurs »** : la sauvegarde passe par la barre d'actions
  globale « Enregistrer » / « Annuler » de la modale Paramètres (les
  boutons dédiés du panneau sont supprimés). Nouveau champ **maxTokens**
  par modèle (défaut pi : 16384).
- **Mémoire projet** : le prompt d'extraction évite désormais de
  dupliquer le contenu déjà présent dans `AGENTS.md`.
- **CI** : mise à jour des actions GitHub (checkout v7, Node 24).
