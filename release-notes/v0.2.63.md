# Pilot v0.2.63

Version de corrections visant à fiabiliser le système d'agents (délégation, onglets, sessions).

## 🐛 Corrections

- L'agent de codage d'un projet se lance désormais correctement quand l'assistant le sollicite (délégation), même si l'onglet agent n'a jamais été ouvert — l'agent par défaut est créé automatiquement en base si besoin.
- Fermer un onglet agent puis changer de projet rapidement ne laisse plus d'onglet « fantôme » résiduel dans l'ancien projet.
- L'arrêt d'un agent ne tue plus systématiquement le reviewer d'orchestration : son cycle de vie est désormais indépendant.
- La délégation ne peut plus viser par erreur un autre onglet agent : elle retombe toujours sur l'agent par défaut.

## ⚡ Améliorations

- État de session correctement conservé et mis à jour à la reprise d'une session.
- Erreurs explicites au lieu d'échecs silencieux quand un agent est introuvable (visibilité / état).
- Chargement fiabilisé de la configuration au démarrage (health check du backend Pi).
