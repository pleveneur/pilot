# Pilot v0.4.19

## 🐛 Corrections

- **Les paquets d'installation sont de nouveau produits.** La fabrication de la
  version précédente s'arrêtait avant d'avoir produit le moindre paquet
  d'installation. C'est réparé : les versions pour Windows, macOS et Linux sont
  désormais construites et publiées normalement.
- **Le service Laya reste optionnel.** Quand sa source n'est pas présente, Pilot
  ne bloque plus la construction. L'application se construit sans ce service, et
  la fonctionnalité Laya revient dès que sa source est disponible.

## ⚠️ Point connu, non corrigé

- **Quelques tests internes restent fragiles.** Certains tests qui isolent le
  travail sur Git et sur le serveur de partage peuvent échouer selon l'ordre
  d'exécution. Cela n'a aucun effet sur les paquets livrés ni sur l'application
  elle-même. La fragilité est signalée et sera traitée séparément.
