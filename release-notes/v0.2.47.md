# Pilot v0.2.47

## ✨ Nouvelles fonctionnalités
- **Boutons de choix / confirmation / saisie dans le chat** : quand l'agent a besoin d'un choix, d'une confirmation ou d'une saisie, il affiche désormais des **boutons cliquables directement dans le chat** au lieu de vous faire taper la réponse. Plusieurs formes sont prises en charge :
  - **Choix unique** : une liste de boutons, un clic répond immédiatement.
  - **Plusieurs choix** : des cases à cocher, avec un **champ de texte optionnel** pour ajouter une précision avant de valider.
  - **Confirmation** : des boutons Oui / Non.
  - **Saisie** : un champ texte avec un bouton Valider.

## ⚡ Améliorations
- **Mode Orchestration autonome** : ces demandes de choix/confirmation/saisie sont désormais **auto-répondues** (sans bloquer l'agent) pour ne pas interrompre le déroulement automatique des tâches.
