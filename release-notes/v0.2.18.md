# Pilot v0.2.18

## ✨ Améliorations

- **Historique complet des évolutions dans la modale de mise à jour** :
  lorsqu'une mise à jour est disponible, la modale n'affiche plus seulement
  les notes de la dernière version — elle présente désormais **toutes les
  évolutions depuis la version installée sur votre poste jusqu'à la
  dernière**. Vous voyez d'un coup d'œil tout ce que vous avez manqué si
  vous avez sauté plusieurs versions. La liste est récupérée depuis les
  GitHub Releases ; en cas d'échec (hors-ligne), la modale retombe sur les
  notes de la dernière version seule.
