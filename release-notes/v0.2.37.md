# Pilot v0.2.37

## ✨ Nouvelles fonctionnalités
- **Commandes projet à distance** (accès distant web) : depuis le web-remote, vous pouvez maintenant **lister, lancer et arrêter** les commandes paramétrées du projet (bouton ▶). La sortie s'affiche **en temps réel** avec l'état *en cours* / *terminé*, directement depuis un téléphone ou un autre poste du réseau Tailscale.

## ⚡ Améliorations
- **Fournisseurs de modèles** : ajout de l'API **`google-generative-ai`** dans la liste des types d'API configurables pour un fournisseur.
