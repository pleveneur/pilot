# Pilot v0.2.72

## ✨ Nouvelles fonctionnalités

- L'assistant de suivi multi-projets peut désormais cibler un projet précis quand il lance les agents, et sa discussion défile automatiquement.
- Détection d'anomalies dans le fonctionnement de l'application, avec un agent de diagnostic dédié pour aider à les comprendre.
- Notifications sonores de l'assistant : un son est joué à la fin d'une tâche, pour un point important, ou quand une question vous est posée.
- Les rappels programmés devenus inutiles sont désactivés automatiquement, sans intervention de votre part.

## ⚡ Améliorations

- Le volume et l'activation du son de l'assistant sont réglables dans les Paramètres.
