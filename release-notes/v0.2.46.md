# Pilot v0.2.46

## ✨ Nouvelles fonctionnalités
- **Code Graph — liens entre fichiers enfin visibles** : la vue « par fichier » affiche désormais les dépendances entre fichiers (les imports sont résolus vers les fichiers réels du projet). Avant, aucun lien n'apparaissait entre les fichiers.
- **Code Graph — progression de construction** : pendant la reconstruction du graphe, un sablier animé s'affiche avec le compteur de fichiers traités et le nom du fichier en cours.

## 🐛 Corrections
- **Code Graph — noms de modules corrects** : les imports affichaient « ts » au lieu du nom du module (ex: « rpc-client »). Les noms réels des modules sont maintenant affichés.
- **Code Graph — clic simple ouvre le fichier** : un clic sur un nœud ouvre directement le fichier dans un onglet (le double-clic a été supprimé).

## ⚡ Améliorations
- **Code Graph — liaisons toujours visibles** : sur les gros graphes, les étiquettes des nœuds ne s'affichent qu'en zoomant, ce qui laisse les liaisons apparentes (elles étaient masquées par les fonds des libellés).
- **Code Graph — couleur dédiée à la relation « contient »** : la relation la plus fréquente a maintenant sa propre couleur, plus facile à distinguer dans la légende.
