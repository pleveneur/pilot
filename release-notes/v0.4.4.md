# Pilot v0.4.4
## ✨ Nouvelles fonctionnalités
- Changer de projet ne ferme plus les agents ouverts : Pilot peut travailler sur plusieurs projets en même temps.
- Clic droit sur un lien .md dans la prévisualisation : choix entre édition et prévisualisation.
- Clic gauche sur un lien .md dans la prévisualisation : ouvre directement en prévisualisation.
## 🐛 Corrections
- Clic sur un lien dans la prévisualisation Markdown ne provoque plus d'erreur « Impossible de lire le fichier ».
- Les adresses web (http) s'ouvrent correctement dans le navigateur.
- La version de développement ne crée plus de double entrée « Pilot » dans le menu Démarrer.
