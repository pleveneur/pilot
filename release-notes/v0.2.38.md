# Pilot v0.2.38

## ✨ Nouvelles fonctionnalités
- **Accès distant — Prompt Builder (🧩)** : construisez un prompt à partir de
  fichiers du projet directement depuis l'interface web. Ajoutez des fichiers via
  le bouton **＋** dans l'arborescence, saisissez vos instructions (ou choisissez
  un template), puis **Assembler** pour prévisualiser, **Envoyer à l'agent** ou
  **Sauvegarder en .md**.
- **Accès distant — projet courant visible** : le nom du projet en cours s'affiche
  désormais dans le titre en haut de l'interface web, ainsi que dans un bandeau de
  l'onglet Chat (avec le chemin complet), pour savoir d'un coup d'œil sur quel
  projet vous travaillez.
