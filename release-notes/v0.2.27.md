# Pilot v0.2.27

## ✨ Nouveautés

- **Export de la conversation agent** : sauvegardez votre chat avec l'agent en
  fichier Markdown (bouton 📥) ou copiez le rendu en HTML dans le presse-papiers
  (bouton ⧉). Idéal pour archiver un travail ou partager une session.

- **Mode « Projet sensible » (local-first)** : protégez vos projets
  confidentiels. Un badge 🔒/🔓 dans la barre de l'agent active/désactive le
  mode par projet. Quand il est actif, la **dictée vocale cloud est bloquée**
  pour garantir que les données ne quittent pas votre machine (utile pour les
  projets d'entreprise ou sensibles).

## 🛡️ Fiabilité & protection des données

- **Conflits de fichiers gérés** : si un fichier ouvert est modifié à
  l'extérieur alors que vous aviez des changements non sauvegardés, Pilot
  affiche désormais un choix clair — **Recharger**, **Garder ma version** ou
  **Voir le diff**. Fini le blocage silencieux ou la perte de travail.

- **Tests multi-plateforme** : la suite de tests (Rust + JS) est maintenant
  exécutée sur **Windows, macOS et Linux** avant chaque publication, pour
  détecter plus tôt les différences entre systèmes.

## 🧹 Nettoyage

- Suppression de fichiers devenus inutiles au fil du développement.
