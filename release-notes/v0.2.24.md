# Pilot v0.2.24

## 🐛 Corrections de bugs

- **Agents plus patients** : le délai d'inactivité par défaut passe de 2 à
  **5 minutes**. Les agents qui font de longues tâches (constructions, tests)
  ne seront plus interrompus prématurément. Vous pouvez ajuster cette durée
  dans **Paramètres → Agents → Timeout d'inactivité (ms)** (jusqu'à 30 min).

- **Message d'arrêt plus clair** : lorsqu'une run s'arrête toute seule
  (temps d'inactivité dépassé, boucle détectée), l'application n'affiche plus
  « Run arrêtée par l'utilisateur » à tort — elle affiche la vraie raison de
  l'arrêt. Ce message ne s'affiche désormais que lorsque vous arrêtez
  réellement la run vous-même.
