# Pilot v0.2.45

## ✨ Nouvelles fonctionnalités
- **Visualisation 2D du graphe du projet (📊)** : le Code Graph s'affiche désormais dans un **onglet dédié** avec une **carte interactive** de votre projet. Les fichiers, fonctions, classes et leurs relations (appels, imports, héritage) sont disposés en graphe que vous pouvez **zoomer, déplacer et explorer**.
  - **Clic sur un nœud** → recentre la vue sur son voisinage (analyse d'impact) ; **double-clic** → ouvre le fichier correspondant.
  - **Survol** → surligne les connexions du nœud.
  - **Couleurs par type** (fichier, classe, fonction…) et **par relation** (appel, import, héritage…), adaptées au thème clair/sombre.
  - **Vue par fichier** : pour les gros projets, les symboles sont regroupés par fichier pour une lecture claire des dépendances entre modules (activée automatiquement au-delà de 250 nœuds).
  - **Sous-graphe contextuel** : affiche le voisinage du fichier en cours d'édition, pour mesurer l'impact d'une modification avant de l'écrire.
  - **Filtres** : par type de relation, par fichier, et recherche de nœud.
  - **Synchronisation avec l'explorateur** : ouvrir un fichier dans l'explorateur met à jour le sous-graphe contextuel.

## 🐛 Corrections
- **Liaisons du graphe invisibles en mode clair** : les connexions entre nœuds sont désormais bien visibles dans les deux thèmes (rendu renforcé avec halo coloré).
- **Boutons du graphe illisibles en mode clair** : les boutons « (Re)construire » et « Actualiser » s'affichent correctement dans le thème clair.

## ⚡ Améliorations
- **Rafraîchissement du graphe** : le bouton « Actualiser » relance le calcul et recentre la vue, même si les données n'ont pas changé ; le graphe se met à jour automatiquement au changement de thème.
- **Barre de réflexion de l'agent** : le trait vertical à gauche de la réflexion de l'agent reprend la couleur d'accent de l'interface, pour une meilleure cohérence visuelle.
