# Pilot v0.2.15

## ✨ Nouveautés

- **💬 Feedback intégré** : un bouton 💬 dans le panneau d'actions permet
  d'envoyer une remarque, un bug ou une idée d'évolution directement depuis
  l'éditeur — par **GitHub** (issue pré-remplie) ou par **email** (sans compte
  GitHub). Vous pouvez aussi consulter les retours déjà envoyés pour éviter un
  doublon. La version de Pilot et votre système d'exploitation sont joints
  automatiquement.
- **📜 Historique des sessions** : un onglet 📜 répertorie toutes vos sessions
  agent (passées et nouvelles), avec recherche full-text, filtres par tag /
  fichier / type, et tags éditables. Consultable hors-ligne.
- **🧠 Context Engine V2** : amélioration de l'auto-contexte projet injecté à
  l'agent (indexation par embeddings, pertinence accru), pour des réponses
  mieux ciblées sans effort de votre part.
- **🤖 Mode Orchestration enrichi** :
  - **Auto-test post-modification** : l'agent vérifie ses changements après
    chaque tâche.
  - **Snapshots & annulation** : possibilité d'annuler une tâche et revenir à
    l'état précédent.
  - **Observabilité des échecs** : suivi détaillé des erreurs du codeur.
- **⚙️ Édition des fournisseurs et modèles IA** : un onglet « Fournisseurs »
  pour configurer vos modèles et alias directement dans l'interface.
- **📁 Fichiers récents** : accès rapide aux fichiers récemment ouverts
  (`Ctrl+Alt+R`).
- **🔔 Notifications desktop** : notification native quand un agent se termine
  (utile en accès distant).
- **📄 Export HTML** : export d'un document Markdown en HTML.

## 🐛 Corrections

- **Menu contextuel coupé** (#1) : un clic droit sur un fichier en bas de
  l'arborescence n'affichait plus un menu tronqué — le menu se repositionne
  désormais pour rester visible.
- Diverses corrections et améliorations de stabilité.
