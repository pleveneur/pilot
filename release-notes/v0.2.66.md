# Pilot v0.2.66

## ✨ Nouvelles fonctionnalités
- **Assistant 🧭** : nouveau mode « user-friendly » (langage simple) pour les réponses de l'assistant, activable dans les Paramètres → Assistant.
- **Agent standard** : détection des boucles d'actions (l'agent qui répète la même action sans avancer est repéré et interrompu).

## 🐛 Corrections
- **Assistant 🧭** : plus de bulle vide avec juste le logo du projet quand l'affichage des pensées et des outils est désactivé.
- **Assistant 🧭** : plus de bulle vide avec juste le nom du projet.
- **Assistant 🧭** : l'onglet Assistant est restauré correctement au redémarrage.
- **Assistant 🧭** : l'onglet de l'agent standard se ferme bien quand l'assistant l'arrête.
- **Assistant 🧭** : les messages d'information s'affichent dans le bon ordre chronologique.
- **Assistant 🧭** : la délégation se fait en arrière-plan quand l'onglet agent est fermé.

## ⚡ Améliorations
- **Agents** : délai d'inactivité par défaut porté à 10 minutes (l'agent ne se met plus en pause trop vite).
