# Pilot v0.2.60

## ✨ Nouvelles fonctionnalités
- **Assistant « réponses courtes »** : dans les Paramètres (onglet Assistant), vous
  pouvez désormais activer le mode « réponses courtes ». Quand il est actif,
  l'Assistant **informe et décide de façon concise**, sans détailler tout ce qui
  se fait, **sauf si vous lui demandez explicitement** de détailler.
- **Mode « Assistant » sur l'accès distant web** : en haut de l'interface web, un
  sélecteur **« 🧭 Assistant » / « 🤖 Agents »** choisit avec quoi discuter. Le
  mode **« Assistant »** (par défaut) affiche une interface **minimaliste** pour
  parler à l'Assistant de suivi multi-projets (lecture seule, **aucun projet à
  ouvrir**) : il peut déléguer des tâches aux agents des projets et répondre sur
  leur avancement. Le mode **« Agents »** restitue l'interface complète (agent du
  projet, fichiers, projets, commandes). Le mode choisi est mémorisé sur votre
  appareil.
