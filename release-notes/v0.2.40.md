# Pilot v0.2.40

## ✨ Nouvelles fonctionnalités
- **Refonte graphique complète** : interface modernisée et épurée (style Linear/Zed) — nouvelle palette de couleurs, typographie, onglets « pills », chat repensé, modales et menus raffinés. Le thème sombre et le thème clair sont tous deux redessinés.
- **Sous-thèmes** : 5 palettes par mode (Sombre : One Dark, Dracula, Nord, Tokyo Night — Clair : GitHub Light, One Light, Solarized Light, Tokyo Night Day). **Aperçu en direct** : le style change immédiatement à la sélection dans les Paramètres, avant enregistrement.
- **Sous-thèmes sur l'accès distant** : le sélecteur de thème est aussi disponible dans l'interface web distante (mémorisé par navigateur).
- **Copier le code d'un bloc** : un bouton ⧉ apparaît au survol de chaque bloc de code de la prévisualisation Markdown pour le copier en un clic.
- **Menus contextuels enrichis** : séparateurs et raccourcis clavier affichés dans les menus (fichier, éditeur).

## 🐛 Corrections
- **Gel de l'application sur les gros projets** : le contexte projet (Context Engine) ignorait la taille des fichiers et pouvait figer l'interface en lisant un gros fichier en entier. Les fichiers de plus de 512 Ko sont désormais ignorés — l'application reste fluide même sur un projet volumineux.

## ⚡ Améliorations
- Onglets spéciaux (agent, terminal, aide, review…) visuellement distincts des onglets d'édition.
